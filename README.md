# my-cli

A simple CLI tool written in Go.

## Usage

```sh
my-cli --name Alice --greeting Hi
# Output: Hi, Alice!
```

## Installation

### Go install (recommended)
```sh
go install github.com/senxu-xs/my-cli@latest
```

### Manual download
Download from [Releases](https://github.com/senxu-xs/my-cli/releases)

## Development

```sh
# Build
go build -o my-cli .

# Run
./my-cli --name Alice --greeting Hi
```
